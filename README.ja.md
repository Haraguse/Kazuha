## 主な機能

Kazuha は、教室での授業やリモート会議向けに、シンプルで効率的なプレゼン体験を提供します。

### 画面注釈

プレゼン支援ツールとしての中核機能を備え、プレゼンソフト上でリアルタイムにマーク、描画、書き込みが可能です。

* **自由描画：** COM 経由で PowerPoint の注釈機能を呼び出し、自由な書き込みに対応。
* **色選択：** 便利なカラーピッカーを搭載。



### 重点フォーカス

フォーカスモードで、観客や学生の注意を重要な情報に集中させます。

* **フォーカス：** 画面の範囲を選択すると、重点領域以外が自動的に **暗く** なります。
* **授業支援：** 学生が重要点をメモする場面で、どこを記録すべきか分かりやすくします。


### 3. 高度なカスタマイズ

Kazuha は柔軟なカスタマイズ性を提供し、個人の習慣やプレゼン用途に合わせて調整できます。
