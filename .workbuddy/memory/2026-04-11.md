# 2026-04-11

## Linux QML Overlay 修复
- **问题**: Qt Fast 版本的 Linux Overlay (LinuxOverlay.qml) 存在两个视觉问题：
  1. 工具栏按钮数量正确但**图标不显示**（只有空白圆圈）
  2. 工具栏**阴影异常**（大块黑色区域，没有正常阴影）
  3. 翻页器箭头图标同样缺失
- **根因分析**:
  - 图标: QML `Image` 加载 SVG 缺少 `sourceSize` 属性 + `visible: false` 导致 ColorOverlay 渲染空源
  - 阴影: `toolbarSurface` 是纯 Rectangle 无任何阴影效果，已 import `Qt5Compat.GraphicalEffects` 但未使用
- **修复内容**:
  1. 所有 Image 组件添加 `sourceSize`(40x40 或 48x48)、`cache: true`、`asynchronous: false`
  2. Image.visible 改为 `status === Image.Ready`（加载完成后才显示），ColorOverlay 同步绑定可见性
  3. 工具栏从纯 Rectangle 改为 Item 包裹 Rectangle + DropShadow 效果（垂直偏移4px、半径12px、颜色 #00000026）
  4. 影响范围：工具栏(8个图标)、左翻页器(2个图标)、右翻页器(2个图标)、橡皮擦弹窗(2个图标)
- **涉及文件**: `ppt_assistant/ui/LinuxOverlay.qml`
- **额外修复**: Component.onCompleted 中添加 `root.rebuildToolbarItems()` 确保首次渲染时数据就绪
