🖱️ 标题栏拖动

点击并拖动标题栏（除了按钮区域）可以移动窗口。双击标题栏可以切换最大化。

// 点击标题栏并拖动鼠标来移动窗口 // 双击标题栏来切换最大化状态

🪟 Windows 11 Snap 支持

将窗口拖至屏幕边缘可以尝试 Windows 11 的 Snap 功能。这个功能完全由操作系统处理。

尝试以下操作：

  • 将窗口拖至屏幕左边缘 → 窗口贴靠到左半屏
  • 将窗口拖至屏幕右边缘 → 窗口贴靠到右半屏
  • 将窗口拖至屏幕顶部 → 窗口最大化
  • 将最大化的窗口拖至屏幕顶部 → 进入 Snap 菜单

💾 自定义标题

可以通过 JavaScript API 更改窗口标题：

window.titlebarManager.setWindowTitle("新标题"); // 或通过 bridge: window.titlebarBridge.set_window_title("新标题");

📋 API 参考

可用的 JavaScript API：

// 通过 titlebarManager window.titlebarManager.minimize(); window.titlebarManager.maximize(); window.titlebarManager.close(); window.titlebarManager.setWindowTitle("标题"); window.titlebarManager.setTheme("dark|light"); window.titlebarManager.getTitlebarHeight(); // 通过 titlebarBridge（直接调用 Python） window.titlebarBridge.minimize(); window.titlebarBridge.maximize(); window.titlebarBridge.close(); window.titlebarBridge.start_drag(); window.titlebarBridge.get_window_state(); window.titlebarBridge.get_window_title(); window.titlebarBridge.set_window_title("新标题");
